# Tashkeel
برنامج لتشكيل الكلمات العربية بناء على بنية الكلمات من حروفها الأساسية دون الحاجة إلى الإعراب
البرنامج لا يقوم بتشكيل الكلمات ولكن يقوم بتشكيلها جزئيا بنسبة كبيرة 
لا يزال البرنامج تحت الإنشاء فالقواعد الموجودة به الآن ليست مكتملة بل مجرد قواعد تجريبية ولكنها ستقوم بجزء كبير من العمل في التشكيل لا يقل عن 50% من التشكيل اللازم للكلمات العربية
